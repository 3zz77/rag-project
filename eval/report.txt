  指标解读
  ──────────────────────────────────────────────────────
  Chunk Recall = 用文档中唯一文本片段验证特定块是否被检索到
    这是真正的「检索召回率」— 不是模糊关键词匹配
  Answer Accuracy = LLM 生成答案与人工标准答案的匹配度
    低 Chunk Recall + 高 Answer Accuracy = LLM 自身知识在补位(幻觉风险)
    高 Chunk Recall + 低 Answer Accuracy = 检索到了但 LLM 没用好
